# Tailwind CSS — Notes

Structured notes on Tailwind CSS — from core concepts through utilities, responsive design, dark mode, custom styles, and directives. Written as a personal reference alongside hands-on practice in Tailwind Play.

---

## Structure

```
├── 00-introduction.md       — what Tailwind is, utility-first concept, vs plain CSS
├── 01-fundamentals.md       — Tailwind Play, class naming pattern, generated CSS layers
├── 02-utilities.md          — padding, margin, sizing, border, background, flex, typography
├── 03-jit-compiler.md       — how JIT works, arbitrary values with []
├── 04-flexbox-and-grid.md   — flex and grid utilities, space-y/x, comparison, practice games
├── 05-responsive-design.md  — mobile-first, breakpoints, max-* variants, how it compiles
├── 06-dark-mode.md          — dark: prefix, @custom-variant setup, JS toggle
├── 07-custom-styles.md      — arbitrary values, @theme tokens, @apply, when to use what
├── 08-directives.md         — @import, @theme, @layer, @apply, @custom-variant, @source
└── 09-misc-utilities.md     — accent, fluid text, file:, selection:, open:, caret, scroll, cursor
```
